# Rolodex
# Project Name: ReloadX

## Project Description
ReloadX is a contact management application designed to help users organize and manage different types of contacts efficiently. The application uses object-oriented programming principles to create a structured and scalable system for storing and displaying contact information. Users can manage business, family, and friend contacts through a centralized system.

## Project Tasks
- **Task 1: Design the class hierarchy**
  - Create the base Contact class
  - Design derived classes for BusinessContact, FamilyContact, and FriendContact
- **Task 2: Implement inheritance**
  - Extend the Contact class with specialized contact types
  - Add unique attributes for each derived class
- **Task 3: Implement composition**
  - Create the Rolodex class to manage a collection of Contact objects
  - Separate contact management from contact data
- **Task 4: Implement interfaces**
  - Create the IDisplayable interface
  - Implement the ShowSummary() method across contact types
- **Task 5: Implement polymorphism**
  - Use virtual methods such as DisplayContact()
  - Override methods in derived classes for specialized behavior
- **Task 6: Test the application**
  - Verify inheritance and polymorphism functionality
  - Ensure contacts display correctly based on object type
- **Task 7: Document the project**
  - Create project documentation
  - Upload project files to GitHub
